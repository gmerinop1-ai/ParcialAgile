## Style Guidelines:

- Primary color: Neutral white or light gray for a professional look.
- Secondary color: Use a shade of blue (#3498db) to convey trust and stability.
- Accent: Green (#2ecc71) for positive actions like approving loans or successful payments.
- Clean and professional fonts for readability.
- Use simple, clear icons to represent actions and data points.
- Clean and well spaced layout for easy information processing.
